# نَغَم — لعبة البلّورات الموسيقية

لعبة "طابق 3" بفكرة جديدة: كل بلّورة لها نغمة، وكل سلسلة تطابقات بتعزف لحن.
كل الرسومات والأصوات متولّدة بالكود — مفيش صور ولا ملفات صوت.

## إزاي تشغّلها
افتح `index.html` في المتصفح على طول، أو شغّل سيرفر بسيط:

```bash
python3 -m http.server 8000
# وافتح http://localhost:8000
```

## الأفكار المميزة (النسخة الأولى)
- **موسيقى حيّة**: كل لون نغمة من سلّم خماسي، والسلاسل بتطلع لحن صاعد. فيه إيقاع خلفي وكوردات.
- **على الإيقاع ×1.5**: اللوحة بتنبض مع الإيقاع، ولو اتحركت والدايرة مقفولة تاخد نقط أكتر.
- **خلط الألوان**: حركة واحدة تعمل تطابقين بلونين مختلفين → بلّورة مخلوطة بتنفع مع اللونين.
- **قطع خاصة**: وتر (4 في صف)، نجمة (L/T)، منشور (5 في صف)، وتركيبات بينهم.
- **حفلة النغم**: لما تكسب، الحركات الباقية بتتحول لأوتار وتنفجر.
- 20 مرحلة: نقط، جمع ألوان، جليد طبقة وطبقتين، ولوحات بأشكال مختلفة.

## الملفات
- `js/engine.js` — منطق اللعبة (بدون رسم، ممكن يتختبر في Node)
- `js/game.js` — الرسم والأنيميشن والتحكم
- `js/audio.js` — الأصوات والإيقاع
- `js/levels.js` — المراحل
- `js/main.js` — الشاشات والخريطة والحفظ

## الاختبارات
